# QuickLog プライバシーポリシー

最終更新日：2026年8月11日

本ポリシーは、アプリ「QuickLog」（以下「本アプリ」）が取得する情報とその取り扱いについて説明します。

## 1. 本アプリの基本方針

本アプリは、ユーザーの記録データを**すべて端末内（ローカル）に保存**します。アカウント登録やログインの仕組みはなく、本アプリの開発者が運用するサーバーへ記録内容が自動的に送信されることはありません。

## 2. 取得する情報

本アプリは以下の情報を取り扱います。

### 位置情報
ホーム画面ウィジェットのタップ時、またはメモ編集時に、端末の位置情報（緯度・経度）を取得します。この取得は**ユーザーの操作のたびに行われるフォアグラウンド処理**であり、バックグラウンドでの継続的な位置追跡は行いません。位置情報の利用を許可しない場合でも、時刻の記録機能は引き続き利用できます。

取得した緯度・経度から大まかな地名を表示するため、Android標準の位置情報解決機能（Geocoder）を利用します。この処理の過程で、位置情報が端末外部のサービス（Google等、OSが提供する仕組みに依存）へ送信される場合があります。

### カメラ・写真
ユーザーが記録にメモや写真を追加する際、任意で以下のいずれかを行えます。

- 端末の写真選択機能（Photo Picker）を通じて、ギャラリー内の既存の写真を1枚選択する
- 端末のカメラ機能を使い、その場で写真を撮影する

写真は本アプリ専用の内部ストレージにのみ保存され、ユーザーが明示的に共有・エクスポートを行わない限り、外部に送信されることはありません。

### メモ・記録内容
ユーザーが入力したメモ、記録の日時、位置情報は、端末内のデータベースにのみ保存されます。

## 3. 情報の利用目的

取得した情報は、以下の目的にのみ利用します。

- 記録の作成・一覧表示・振り返り機能の提供
- 記録に紐づく地名の表示（逆ジオコーディング）
- ユーザーが明示的に指示した場合の、記録データのエクスポート・共有・バックアップ

## 4. 第三者への提供

本アプリは、広告表示や分析目的でのデータ収集（アナリティクスSDK等）を一切組み込んでいません。ユーザーが自らの意思で以下の操作を行った場合を除き、記録データが外部に送信されることはありません。

- Android標準の共有機能（共有シート）を使って、他のアプリ（メモアプリ、クラウドストレージ等）へ記録を送る場合
- バックアップ機能を使って、ユーザー自身が指定した端末内フォルダやクラウドストレージにファイルを保存する場合

これらの操作は、いずれもユーザー自身の操作によって開始されるものであり、本アプリの開発者が内容を閲覧・収集することはありません。

## 5. データの削除

以下の方法で、いつでもデータを削除できます。

- アプリ内の「ゴミ箱」機能から、個別の記録を完全に削除する
- 本アプリをアンインストールすることで、端末内に保存された全ての記録・写真・設定情報が削除される（本アプリのデータはすべて端末内にのみ存在するため、アンインストールによって完全に消去されます）

## 6. 権限について

本アプリが求める権限とその理由は以下の通りです。

| 権限 | 理由 |
|---|---|
| 位置情報（ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION） | 記録作成時に位置情報を付与するため |
| カメラ（CAMERA） | 記録に写真をその場で撮影して添付するため |
| インターネット（INTERNET） | 地名解決（逆ジオコーディング）のため |
