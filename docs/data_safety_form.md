# QuickLog データセーフティフォーム 回答案

Google Play Consoleの「アプリのコンテンツ」→「データセーフティ」で入力する内容の下書きです。
実際の入力画面の項目名・選択肢はGoogleの仕様変更により変わることがあるため、
提出前に必ず最新のPlay Console画面と照らし合わせて確認してください。

---

## Q. アプリはユーザーデータを収集または共有していますか？

**→ はい**（位置情報・写真・ユーザーが入力するメモを扱うため）

---

## データの種類ごとの回答

### 位置情報

| 項目 | 回答 |
|---|---|
| 収集する位置情報の種類 | 概略の位置情報／正確な位置情報（両方） |
| このデータは収集されますか | はい |
| このデータは共有されますか | いいえ（自動的な第三者共有は行わない） |
| 収集は必須か任意か | 任意（権限を拒否しても他機能は利用可能） |
| 収集の目的 | アプリの機能（記録への位置情報付与、地名表示） |
| ユーザーはデータ削除を要求できるか | はい（アプリ内削除、またはアンインストール） |

**補足メモ（審査担当者向けの説明が必要な場合）**：
逆ジオコーディング（地名表示）のため、Android標準のGeocoder APIを経由して位置情報がOSレベルの外部サービスに渡ることがあります。これは本アプリが独自に外部送信しているものではなく、Android OSの標準機能に依存します。

---

### 写真と動画

| 項目 | 回答 |
|---|---|
| このデータは収集されますか | はい |
| このデータは共有されますか | いいえ（ユーザーが明示的に共有操作をした場合を除く） |
| 収集は必須か任意か | 任意 |
| 収集の目的 | アプリの機能（記録への写真添付） |
| ユーザーはデータ削除を要求できるか | はい |

**補足メモ**：
写真はPhoto Picker（写真選択機能）またはカメラ撮影を通じて、ユーザーが個別に選択・撮影したもののみを扱う。ギャラリー全体への包括的なアクセス権限（READ_MEDIA_IMAGES等）は要求していない。

---

### ユーザーが作成したコンテンツ（メモ本文）

| 項目 | 回答 |
|---|---|
| データの種類 | その他のユーザー生成コンテンツ |
| このデータは収集されますか | はい（端末内保存のみ、開発者サーバーへの送信なし） |
| このデータは共有されますか | いいえ |
| 収集の目的 | アプリの機能 |
| ユーザーはデータ削除を要求できるか | はい |

---

### 収集していないことを明記できる項目

以下は本アプリでは収集していないため、Play Console上で「収集しない」を選択してください。

- 個人情報（氏名、メールアドレス、電話番号、ユーザーID等） — アカウント機能がないため収集なし
- 財務情報
- 健康・フィットネス情報
- メッセージ（SMS・メール本文等）
- 連絡先
- アプリのアクティビティ（アプリ内検索履歴、インストール済みアプリの一覧等） — アナリティクスSDK不使用
- ウェブ閲覧履歴
- 端末やその他のID（広告ID等） — 広告SDK不使用

## データのセキュリティに関する質問

| 項目 | 回答 |
|---|---|
| データは転送時に暗号化されていますか | 該当なし、または「はい」（ユーザーが共有操作をした場合のみ通信が発生し、その通信はAndroid標準の共有機構・HTTPS経由） |
| ユーザーはデータの削除を要求できますか | はい |
| このアプリはGoogle Playのファミリーポリシーに準拠していますか | 対象年齢設定に応じて別途確認 |

---

## 全体を通しての設計方針（審査対応の根拠として）

- 本アプリにはアカウント・ログイン機能がなく、全データは端末のローカルストレージ（Room DB、内部ファイルストレージ）にのみ存在する
- ネットワーク通信が発生するのは以下の場合のみ：
  1. 地名解決（Geocoder、OS依存）
  2. ユーザーが明示的に選択した共有・エクスポート操作
  3. ユーザーが明示的に選択したバックアップ先への書き込み（ローカルフォルダ、クラウドストレージのアプリ経由の場合も含む）
- 広告SDK・アナリティクスSDK・クラッシュレポートSDKは組み込んでいない（2026年8月時点の実装）
