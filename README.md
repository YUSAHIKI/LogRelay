# QuickLogWidget（MVP雛形）

「ウィジェットをワンタップ→位置＋時刻だけ記録」を最速で検証するための最小構成です。

## 開き方
1. Android Studio（最新の Koala 以降推奨）でこのフォルダを開く（`File > Open`）
2. Gradle Sync が走るのでそのまま待つ（初回はライブラリDLで数分かかる）
3. 実機 or エミュレータ（API 26以上）で `app` を実行
4. ホーム画面を長押し→ウィジェット一覧から「QuickLog」を配置
5. 初回はアプリ本体を一度起動して位置情報の権限を許可しておく（ウィジェット単体では権限ダイアログを出せないため）

## 今回の核心部分
- `widget/QuickRecordWidget.kt` … ウィジェットA（即記録型）のUIとタップ時のアクション
- `util/LocationHelper.kt` … ウィジェットタップという「一瞬で終えたい」文脈での位置情報取得（4秒タイムアウト、失敗しても時刻だけは残す設計）
- `data/RecordRepository.kt` … ウィジェットとアプリ本体の両方から呼ばれる保存ロジック
